Ereignisse

Gleiche Schalter wie im Spielmenü (Taste J). Ausgeschaltete Ereignisse zeigen die Overlays nicht an. „Test“ spielt den Effekt einmal in allen offenen Overlays ab, auch wenn der Schalter aus ist.

Todeszähler

Zählt automatisch, wenn deine Herzen auf 0 fallen. Wird gespeichert und übersteht Neustarts. „Stream“ vor jedem Stream auf 0 setzen.
